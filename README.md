# 3. Communication & Availability

**Main Communication Channel:** WhatsApp Group Chat will be used for real-time communication, daily updates, discussions, and urgent issues.

**Core Working Hours:** 1:15 PM – 4:30 PM IST, covering the SW Daily Block and standup sessions.

**Communication Guideline:** If a team member remains blocked on a task for more than 30 minutes, they must immediately inform the WhatsApp group rather than continuing to struggle with the issue silently.

---

# 4. Development Workflow & Team Standards

**GitHub Branching Policy:** Direct commits to the `main` branch are not permitted. Each team member must work through a separate feature branch, such as `feature/jwt-auth` or `feature/ticket-schema`.

**Pull Request Requirements:**

* Each PR must receive at least **one teammate review and approval** before it can be merged.
* Every PR description must clearly mention what was implemented, provide evidence of testing, and include the applicable concept ID.

**Daily Journal Requirement:** Every team member must complete and submit their individual daily journal before **11:59 PM** each day.

---

# 5. Conflict Resolution & Accountability

### 1. Architecture Decisions

If there is a disagreement regarding the project architecture, the team will discuss the issue for a maximum of 15 minutes. If no agreement is reached, the team will either conduct a vote or seek guidance from the mentor.

### 2. Progress Issues & Blockers

Any delays, blockers, or differences in progress should be openly communicated during the daily standup.
Based on the situation, tasks may be redistributed or team members may pair-program to help resolve the issue.
